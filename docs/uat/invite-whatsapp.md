# UAT invite (WhatsApp)

Placeholders only. Send one message per clinic from the PO's own WhatsApp, as an individual chat (not a group). The code
is pasted at send time; do not save it in this file or in a chat export.

Message 1:
> Hello `<owner first name>`, this is `<PO name>`. Thank you for trying clinicOS at `<clinic name>`. Your trial is free
> until `<UAT exit date>`. Start here: `<production signup link>`

Message 2 (separate, so the code is easy to copy):
> Your code (works once): `<CODE: paste at send time>`

Message 3:
> The short guide is here: `<tester guide link>`. If anything is confusing or broken, message `<feedback channel>`. I read
> every message. Tip: on iPhone, open the link in Safari, then Share > Add to Home Screen.

Reminders for the sender:
- Never forward codes between clinics or groups.
- If a code is shared by mistake, tell the PO to cancel the redemption and issue a new code (`docs/runbooks/uat.md`).
- Do not ask testers to send patient details in WhatsApp.
