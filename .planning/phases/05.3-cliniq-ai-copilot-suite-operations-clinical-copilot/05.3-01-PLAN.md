<objective>
Implement Wave 1 foundation for the CliniQ AI Copilot Suite:
1. Install and configure Vercel AI SDK (`ai@^4.0.0`, `@ai-sdk/react@^1.0.0`, `@ai-sdk/openai@^1.0.0`).
2. Extend `lib/ai/types.ts` and `lib/ai/client.ts` with typed Zod schemas and universal AI gateway resolution supporting both OpenAI-compatible endpoints and `MockAiProvider`.
3. Create `lib/ai/sanitizer.ts` for strict DPDP Act direct PII scrubbing (Name, Phone, Aadhaar, ABHA, Address).
4. Create `lib/ai/knowledge/product-manifest.ts` providing grounded ClinicOS feature documentation and navigation paths for zero-hallucination workflow guidance.
5. Create `lib/ai/tools/operations-tools.ts` and `lib/ai/tools/clinical-tools.ts` with strict Zod parameters and server-side RBAC validation.
6. Create Next.js 15 App Router streaming route handlers (`app/api/ai/operations-copilot/route.ts` and `app/api/ai/clinical-copilot/route.ts`) enforcing sliding-window pruning, two-phase tool execution, and the mandatory clinical advisory disclaimer.
7. Verify all schemas, tools, sanitizers, and handlers with unit tests in `tests/ai/gateway-tools.spec.ts`.
</objective>

<threat_model>
| Threat ID | STRIDE Category | Component | Description | Severity | Mitigation |
|-----------|-----------------|-----------|-------------|----------|------------|
| T-05.3-01 | Information Disclosure | `lib/ai/sanitizer.ts` / `app/api/ai/*` | Direct patient identifiers (Full Name, 10-digit Indian Mobile, Aadhaar, ABHA ID, Street Address) leaked to external LLM providers in API payloads, violating the Indian DPDP Act 2023. | Critical | `sanitizePatientContextForPrompt` and regex interceptors purge all direct PII before model prompt construction, retaining only de-identified clinical tokens (Age, Sex, Vitals, Chronic Conditions list). |
| T-05.3-02 | Elevation of Privilege | `lib/ai/tools/operations-tools.ts` | Natural language conversational prompts trick LLM tools into executing administrative mutations (e.g. nurse modifying doctor visit notes, receptionist changing consultation fee). | Critical | Every tool checks authenticated session role (`user.app_metadata.role`) and returns `UNAUTHORIZED_ROLE` if role lacks required permissions. |
| T-05.3-03 | Denial of Service / Token Burn | `app/api/ai/operations-copilot/route.ts` | Long clinic chat sessions send unbounded message history or infinite tool recursion loops, burning tokens and exhausting API budgets. | Medium | Pin `export const maxDuration = 30`, enforce deterministic sliding-window pruning (`messages.slice(-5)`), and set `maxSteps: 3` to cap recursive tool turns. |
| T-05.3-04 | Repudiation / Audit Bypass | `lib/ai/tools/operations-tools.ts` | Copilot mutations occur without attributing the action to the confirming human staff member or marking the channel. | High | Operations tool preview payloads require staff confirmation, logging audit events with `actor_id = confirming_user_id` and `metadata.channel = 'operations_copilot'`. |
</threat_model>
