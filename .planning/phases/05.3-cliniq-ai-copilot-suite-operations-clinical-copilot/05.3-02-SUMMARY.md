## 4. Key Design Decisions

1. **Two-Phase Action Card Locking (D-03):** To prevent accidental double booking or race conditions, preview cards enter a disabled loading state on the first click, execute the booking mutation, and lock into an immutable green badge (`✓ Confirmed on Calendar • Slot Locked`).
2. **Global Cmd+K Dedication (D-01):** Per `05.3-UI-SPEC.md`, `Cmd+K` / `Ctrl+K` is dedicated to opening the CliniQ Operations Copilot drawer, while global search is triggered via the `/` key or clicking the search box.
3. **Session Persistence with Clear-All Reset (D-04):** Conversation thread is persisted in client `sessionStorage` across route transitions, with a `[New Chat]` button allowing instant thread resetting.
