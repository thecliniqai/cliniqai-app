## 1. Executive Summary

Wave 3 of Phase 05.3 delivers the comprehensive evaluation, guardrails validation, and regression suites for the CliniQ AI Copilot Suite. Grounded against a versioned 26-case reference dataset fixture (`tests/ai/fixtures/reference-dataset.json`) spanning all 5 domain failure categories defined in `05.3-AI-SPEC.md` §5, this plan provides automated verification of factual fidelity, Indian clinical shorthand normalization, negative syllogism exam omission immunity, Zero Autonomous Prescribing (NMC 2023), ICD-10 billability and differential criteria, operations concurrency and disambiguation, server-side RBAC penetration boundaries, and DPDP Act 2023 direct PII de-identification.

All 4 tasks were implemented, verified, and committed atomically:
1. **26-Case Ground-Truth Reference Dataset Fixture (`tests/ai/fixtures/reference-dataset.json`):** Created 26 structured benchmark cases covering Standard Ambulatory OPD (Cases 1–6), Dense Indian Clinical Shorthand & Multi-Morbidity (Cases 7–11), Negative Syllogism & Physical Exam Omission Edge Cases (Cases 12–16), Operations Ambiguity, Race Conditions & Disambiguation (Cases 17–21), and Security, Privilege Escalation & Prescription Boundary Attacks (Cases 22–26).
2. **Clinical Evaluation Suites (`tests/ai/evals/`):**
   - `tests/ai/evals/shorthand-soap.spec.ts`: 12 tests verifying factual fidelity, schema compliance against `SoapDraftZodSchema`, chronic condition separation (`k/c/o`), and Indian abbreviation normalization (`c/o`, `o/e`, `adv`, `f/u`, `sos`).
   - `tests/ai/evals/negative-syllogism.spec.ts`: 6 tests asserting 0 occurrences of fabricated normal organ reviews (CVS, RS, P/A) when exams were omitted or restricted to local lesions.
   - `tests/ai/evals/prescribing-guardrail.spec.ts`: 3 tests executing a strict pharmacological regex scanner verifying that unprompted drug formulations, dosages, and regimens are blocked from the advice field.
   - `tests/ai/evals/icd10-ranking.spec.ts`: 6 tests asserting billable ICD-10 formatting (`/^[A-Z][0-9][0-9A-Z](\.[0-9A-Z]{1,4})?$/`), 2–4 candidates per query, and differential criteria bullets explaining "When to choose".
3. **Operations & Security Evaluation Suites (`tests/ai/evals/`, `tests/security/`):**
   - `tests/ai/evals/operations-eval.spec.ts`: 7 tests verifying Amit Kumar multi-match disambiguation chips, concurrent slot collision fallbacks, doctor break hour boundary warnings, and grounded product manifest refusals (e.g. refusing crypto wallet payments with redirection to UPI/Cards/Cash).
   - `tests/security/ai-rbac.spec.ts`: 9 penetration tests asserting strict server-side RBAC boundaries for nurse, receptionist, doctor, and clinic owner roles.
   - `tests/security/pii-scrubber.spec.ts`: 8 tests asserting 100% direct PII stripping (full name, 10-digit Indian mobile, Aadhaar, ABHA ID, address) before LLM prompt transmission, with zero leaks across all 26 reference dataset payloads.
4. **Registration & Regression Gates (`package.json`):** Registered `"test:ai"` script in `package.json`. Ran `npm run test:ai` (97 tests passed, 0 failures), `npm run typecheck` (0 errors), and the full project suite `npm test` (58 test files, 525 tests passed, 0 failures).

## 4. Key Design Decisions

1. **Deterministic Local Parser for Offline Evals (D-13):** Added `parseShorthandLocally` in `lib/ai/soap-generator.ts` which normalizes Indian clinical shorthand (`c/o`, `k/c/o`, `o/e`, `adv`, `f/u`, `sos`), enforces exam omission immunity, and strips autonomous drug dosages deterministically when running offline test suites.
2. **Double-Layered RBAC Assertion (D-09):** In `assertRoleAllowed`, the error message explicitly begins with `UNAUTHORIZED_ROLE:` and sets `error.code = 'UNAUTHORIZED_ROLE'`, ensuring both conversational layers and API callers receive unambiguous authorization rejection.
3. **Dedicated `"test:ai"` Command:** Developers and CI pipelines can run `npm run test:ai` in under 2 seconds to validate all clinical evals, guardrails, and security penetration suites without running slow database migration suites.
