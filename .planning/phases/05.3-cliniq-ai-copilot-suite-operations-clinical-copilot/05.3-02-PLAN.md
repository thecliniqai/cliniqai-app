<objective>
Implement Wave 2 Global Operations Copilot UI and shell-wide integration:
1. Construct TailAdmin-compliant chat message bubble primitives (`components/ai/chat-bubble.tsx`).
2. Construct interactive action cards conforming to `05.3-UI-SPEC.md`:
   - `ActionPreviewCard`: Booking, rescheduling, and cancellation confirmation with loading states, locked status badges (`✓ Confirmed on Calendar • Slot Locked`), and shift warning indicators.
   - `PatientDisambiguationCard`: Clickable candidate chips displaying Name, normalized +91 mobile, Age/Gender, and Last Visit date.
   - `ConflictRecoveryCard`: Explanatory message and 2–3 clickable alternative slot recommendation chips.
   - `QuickRegistrationCard`: Inline patient registration with `<PhoneInput>` and `[Register & Book Patient]` CTA.
3. Construct `OperationsCopilotDrawer` (`components/ai/operations-copilot-drawer.tsx`): 420px slide-over right drawer, `@ai-sdk/react` (`useChat`), token-frugal sliding-window payload, `sessionStorage` persistence, zero-state with 3 starter chips, and sticky header/footer.
4. Mount the Copilot in `components/layout/app-header.tsx` with a top-header button (to the left of `NotificationBell`) and global `Cmd+K` / `Ctrl+K` keyboard shortcut toggle.
5. Create comprehensive tests in `tests/ai/operations-copilot-ui.spec.ts`.
</objective>

<threat_model>
| Threat ID | STRIDE Category | Component | Description | Severity | Mitigation |
|-----------|-----------------|-----------|-------------|----------|------------|
| T-05.3-05 | Race Condition / Double Booking | `components/ai/action-preview-card.tsx` | Double-clicking `[Confirm Appointment Booking]` creates duplicate database records or commits a slot taken by another staff member during preview. | High | Preview card enters optimistic disabled/loading state on first click, executes atomic booking service with slot availability re-check, and surfaces `<ConflictRecoveryCard />` on collision. |
| T-05.3-06 | Information Disclosure / XSS | `components/ai/chat-bubble.tsx` | Untrusted LLM output or patient notes containing script tags or malicious markdown injected into chat stream. | Medium | Render chat text using sanitized React text nodes or safe markdown without `dangerouslySetInnerHTML`. |
| T-05.3-07 | Session Contamination | `components/ai/operations-copilot-drawer.tsx` | Active chat history in `sessionStorage` leaks across different logged-in users on shared clinic workstations. | High | Scope `sessionStorage` key by active `userId` and `tenantId` (`clinicos_copilot_${tenantId}_${userId}`); clear on user logout or tenant switch. |
</threat_model>
