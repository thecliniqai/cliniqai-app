4. Slot alternative recommendations: Highlighted time-slot pill in conflict recovery cards.
5. Focused input borders: `focus:border-[#1769E0] focus:ring-1 focus:ring-[#1769E0]`.

## Surface & Component Specifications

### 1. Global Operations Copilot Drawer

#### 1.1 Trigger Placement (`components/layout/app-header.tsx`)
- Placed in top header directly to the left of the `NotificationBell`.
- Icon button: 40 × 40px, 8px radius, `text-gray-500 hover:text-gray-900 hover:bg-gray-100 transition-colors`.
- Icon: `Bot` or `Sparkles` from `lucide-react` (18px).
- Shortcut hint: Tooltip showing `CliniQ Copilot (⌘K)`.
- Global keyboard listener: `Cmd+K` (macOS) and `Ctrl+K` (Windows/Linux) toggles drawer open/closed.

#### 1.2 Drawer Architecture (`components/ai/operations-copilot-drawer.tsx`)
```text
┌──────────────────────────────────────────────────────────────┐
│ [✦ CliniQ AI] Operations Copilot         [↺ New Chat] [✕]    │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│ [User] Book an appointment for Rajesh Kumar tomorrow 10am   │
│                                                              │
│ [Copilot] I found Rajesh Kumar (+91 98220 12345).           │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 📅 Booking Confirmation Preview                          │ │
│ │ Patient:  Rajesh Kumar (38y M) • +91 98220 12345         │ │
│ │ Doctor:   Dr. Anjali Sharma (General Physician)          │ │
│ │ Slot:     Thu, 29 Oct 2026 • 10:00 AM – 10:15 AM         │ │
│ │ Fee:      ₹500                                           │ │
│ │                                                          │ │
│ │ [ Cancel Booking Action ]  [ Confirm Appointment Booking ]│ │
│ └──────────────────────────────────────────────────────────┘ │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ Ask anything or describe an action...               [ ▲ ]│ │
│ └──────────────────────────────────────────────────────────┘ │
│ [Today's Queue] [Check Availability] [Quick Patient Search]  │
└──────────────────────────────────────────────────────────────┘
```
- **Geometry:** Width 420px on desktop (`max-w-md`), full-width (`100vw`) on mobile (`< 640px`).
- **Surface:** Solid `#FFFFFF` surface with Level 2 shadow (`0 12px 32px rgba(23, 24, 26, 0.12)`), right hairline border `border-l border-[#E4E5E7]`.
- **Backdrop:** Semi-transparent `rgba(23, 24, 26, 0.20)` with `backdrop-blur-xs`.
- **Animation:** Slide-in from right (160ms ease-out). Respects `prefers-reduced-motion`.
- **Keyboard listener:** ESC key closes drawer immediately.
- **Header:** Sticky top bar (height 64px, 24px horizontal padding) featuring CliniQ AI logo icon, "Operations Copilot" title (`20px / 600`), `[Start New Chat]` ghost button (`RotateCcw` icon), and `[Close]` button (`X` icon).
- **Body Area:** Scrollable message list with auto-scroll on streaming output.
  - User messages: Right-aligned bubble, `bg-[#F1F2F4] text-[#17181A]`, radius 12px with bottom-right corner 4px.
  - Assistant messages: Left-aligned bubble, `bg-white border border-[#E4E5E7] text-[#17181A]`, radius 12px with bottom-left corner 4px.
- **Input Area:** Sticky bottom panel with 16px padding.
  - Textarea / input with focus ring `focus:border-[#1769E0] focus:ring-1 focus:ring-[#1769E0]`.
  - Send action button: 40 × 40px `#1769E0` button with upward arrow icon (`ArrowUp`).
  - Suggested prompt chips row above input:
    - `[Today's Queue Status]`
    - `[Check Doctor Availability]`
    - `[How do I configure billing?]`

#### 1.3 Interactive Action Cards
- **Booking Confirmation Card:**
  - Structured metadata grid (Patient name, phone, doctor, slot, consultation fee).
  - Primary button: `[Confirm Appointment Booking]` (brand primary `#1769E0`).
  - Secondary button: `[Cancel Booking Action]` (white background, border `#C9CCD1`).
  - Post-Confirmation Locked State: Buttons are replaced with a non-interactive green status badge:
    `✓ Confirmed on Calendar • Slot Locked` (`bg-emerald-50 text-emerald-800 border border-emerald-200`) and a link `[Open in Calendar ↗]`.
- **Patient Disambiguation Card:**
  - Rendered when patient search yields 2 or more candidates.
  - Candidate chips layout:
    ```text
    ┌────────────────────────────────────────────────────────┐
    │ 👤 Rajesh Kumar • +91 98220 12345 • 42y M • Last: 12d  │
    └────────────────────────────────────────────────────────┘
    ┌────────────────────────────────────────────────────────┐
    │ 👤 Rajesh Kumar • +91 94440 98765 • 29y M • Last: New  │
    └────────────────────────────────────────────────────────┘
    ```
  - Clicking a candidate chip selects that patient, locks identity, and automatically advances the conversation.
- **Conflict Recovery Card:**
  - Explanatory alert: `! Slot 10:00 AM was just booked by another clinician.`
  - Prompt: `Available alternatives with Dr. Sharma today:`
  - Alternative slot chips:
    `[ 10:30 AM ]` `[ 11:15 AM ]` `[ 04:00 PM ]`
  - Clicking any chip instantly generates an updated confirmation card for the chosen slot.
- **Inline Quick Registration Card:**
  - Rendered when user requests to book a new patient not yet registered.
  - Compact inline fields:
    - Full Name (Input, 40px height)
    - Mobile Number (`<PhoneInput>` with `🇮🇳 +91`)
    - Gender / Age (compact 2-column)
  - Primary CTA: `[Register & Book Patient]`

### 2. Consultation Clinical Copilot Panel

#### 2.1 Placement & Docking (`components/consultation/consultation-workspace.tsx`)
- Hidden by default to preserve a distraction-free clinical environment.
- Opened via a dedicated toolbar button in the sticky workspace header:
  `[ ✦ AI Assistant ]` (`bg-indigo-50 text-indigo-700 border border-indigo-200 hover:bg-indigo-100 font-semibold text-xs py-2 px-3 rounded-lg flex items-center gap-1.5`).
- On desktop (`>= 1024px`): Slides in as a docked right-hand panel (380px fixed width) alongside the consultation form, shrinking the central form comfortably (`max-w-[760px]`).
- On mobile (`< 1024px`): Opens as a full-screen slide-over drawer with a close button.

#### 2.2 SOAP Note Structuring & Granular Insertion
```text
┌──────────────────────────────────────────────────────────────┐
│ [✦ CliniQ AI] Clinical Copilot                          [✕]  │
├──────────────────────────────────────────────────────────────┤
│ Raw Clinical Shorthand:                                      │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ c/o fever 3d, throat pain, dry cough. o/e throat         │ │
│ │ congested, tonsils enlarged, chest clear. adv warm gargle│ │
│ └──────────────────────────────────────────────────────────┘ │
│ [🎙 Dictate]                          [ Generate SOAP Draft ]│
├──────────────────────────────────────────────────────────────┤
│ ✦ AI Suggested Draft (Verified from notes)                   │
│                                                              │
│ Chief Complaints:                                            │
│ • Fever (3 days) • Sore throat (3 days)                      │
│                                   [Insert Chief Complaints]  │
│                                                              │
│ Physical Examination:                                        │
│ Pharynx congested. Bilateral tonsils grade 2 enlarged.       │
│                               [Insert Examination Findings]  │
│                                                              │
│ Clinical Advice:                                             │
│ Warm saline gargles 3-4 times daily. Steam inhalation.       │
│                                     [Insert Clinical Advice] │
│                                                              │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ [ Insert All Sections ]                                  │ │
│ └──────────────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────┤
│ ⚠️ Clinical Advisory: CliniQ AI is an informational         │
│ assistant, not a licensed healthcare professional. All      │
│ information must be evaluated under independent judgment.    │
└──────────────────────────────────────────────────────────────┘
```
- **Granular Actions:** Each section card provides an independent insert button (`[Insert Chief Complaints]`, `[Insert Examination Findings]`, `[Insert Clinical Advice]`).
- **Batch Action:** Top/Bottom primary CTA: `[Insert All Sections]`.
- **Existing Content Collision Handling:** If the target form field already contains text:
  - An inline dialog appears with two explicit choices:
    - `[Append to Existing Notes]` — adds AI draft below existing text separated by a newline.
    - `[Replace Existing Notes]` — completely replaces field text with AI draft.
- **Clinical Provenance Tracking:**
  - Upon accepting any draft section, the client marks `metadata.ai_assisted = true` and pushes the section key into `metadata.ai_sections_used` array.
  - Final signed prescription PDF generated in `@react-pdf/renderer` remains 100% clean with zero AI watermarks.

#### 2.3 Context-Aware ICD-10 Coding Helper
- Accessed from the Clinical Copilot or via an inline `[Suggest ICD Codes]` button on the Diagnosis form section.
- Returns top 2–4 ranked candidate cards:
  ```text
  ┌──────────────────────────────────────────────────────────┐
  │ J03.90 — Acute tonsillitis, unspecified                  │
  │ Acute infection of tonsils without specified organism.    │
  │ • When to choose: General acute viral/bacterial OPD cases │
  │                                   [ Apply Diagnosis Code] │
  └──────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────┐
  │ J03.0 — Streptococcal tonsillitis                        │
  │ Laboratory-confirmed or classic bacterial presentation.  │
  │ • When to choose: Rapid antigen positive or petechiae    │
  │                                   [ Apply Diagnosis Code] │
  └──────────────────────────────────────────────────────────┘
  ```
- Clicking `[Apply Diagnosis Code]` automatically appends the code and WHO label to the patient's visit diagnoses list.

#### 2.4 Clinical Q&A & Mandatory Advisory Banner
- Doctors can type open-ended clinical questions ("Pediatric dosage of Cefixime for 14kg child", "Management of gestational hypertension").
- Response renders clinical reference points.
- Mandatory persistent advisory banner pinned to the bottom of every clinical response:
  `⚠️ Clinical Advisory: CliniQ AI is an informational assistant, not a licensed healthcare professional. All information must be evaluated and verified under independent clinical judgment.`
- Direct PII stripping: Direct identifiers (Patient Name, Mobile, Aadhaar/ABHA, Address) are scrubbed before payload transmission. A subtle security notice appears at the top:
  `🔒 De-identified Query (Direct PII removed)`
