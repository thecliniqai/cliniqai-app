<objective>
Deliver the Doctor's Cabin workspace (`/cabin`), dynamic role-based navigation in the sidebar and header, and clinic profile practitioner settings:
1. Update `app-sidebar.tsx`, `app-header.tsx`, and `app-layout-shell.tsx` to handle role-based navigation (Owners/Admins access all sections, Doctors focus on Doctor's Cabin, Nurses/Receptionists focus on Operations).
2. Build the Doctor's Cabin route (`/cabin`) and components (`doctor-cabin-view.tsx`, `my-queue-card.tsx`) displaying the doctor's assigned queue, pre-filled vitals, active consultation resumption banner, and 1-tap `Start Consultation` link to `/consultation/[id]`.
3. Update Clinic Profile settings (`clinic-profile-form.tsx`) to support configuring whether the owner is a practicing doctor, doctor registration number, default OPD consultation fees, and accepted payment methods.
4. Add comprehensive unit tests in `tests/cabin/navigation-roles.spec.ts`.
</objective>
