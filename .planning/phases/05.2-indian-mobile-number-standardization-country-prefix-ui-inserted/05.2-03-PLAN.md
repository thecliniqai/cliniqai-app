Implement Wave 3 of Phase 05.2:
1. Upgrade backend patient and visit search actions (`features/patients/actions.ts`, `features/visits/actions.ts`) to support flexible phone searching: users can type bare 10-digit numbers or partial numeric substrings (>= 3 digits) and match against stored E.164 (`+91XXXXXXXXXX`) database records without typing `+91`.

4. Upgrade `components/visits/visits-register-view.tsx` to render clean 5+5 formatted subscriber phone numbers (`98765 43210`).
5. Run full end-to-end regression across all Phase 05.2 tests and verify TypeScript clean build.
