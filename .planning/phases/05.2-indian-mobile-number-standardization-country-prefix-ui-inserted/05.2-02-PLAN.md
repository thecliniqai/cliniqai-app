  <action>
    1. Create `components/ui/phone-input.tsx`:
       - `"use client";`
       - Interface `PhoneInputProps`:
         - Extends `Omit<React.InputHTMLAttributes<HTMLInputElement>, "value" | "onChange">`
         - `value?: string`: Can receive bare 10-digit number or E.164 (`+91XXXXXXXXXX`).
         - `onChange?: (tenDigits: string, e164: string) => void`: Emits 10 subscriber digits and normalized E.164 string.
         - `invalid?: boolean`: Renders error border and focus ring when true.
         - `disabled?: boolean`: Handles disabled styling.
       - Internal state `digits` initialized with `extractTenDigits(value)`.
       - `useEffect` synchronizes `digits` when `value` prop changes.
       - `handleChange`: Strips non-digits (`raw.replace(/\D/g, "").slice(0, 10)`), updates `digits`, and invokes `onChange(cleaned, cleaned.length === 10 ? "+91" + cleaned : cleaned)`.
       - `handlePaste`: Prevents default, extracts 10 digits from clipboard data using `extractTenDigits(pasted).slice(0, 10)`, updates `digits`, and calls `onChange`.
       - DOM Layout & Styling:
         - Wrapper container:
           - Base: `relative flex items-center w-full min-h-[44px] rounded-lg border bg-white shadow-theme-xs transition-colors`
           - Normal state: `border-gray-300 focus-within:border-[#1769E0] focus-within:ring-3 focus-within:ring-[#1769E0]/15`
           - Invalid state (`invalid === true`): `border-[#B42318] focus-within:border-[#B42318] focus-within:ring-[#B42318]/15`
           - Disabled: `opacity-50 bg-gray-50 cursor-not-allowed`
         - Left Prefix Badge:
           - Inset container: `flex items-center gap-1.5 px-3 py-2 select-none border-r border-gray-200 bg-gray-50/80 rounded-l-lg text-gray-700 font-medium text-sm shrink-0`
           - Attributes: `aria-hidden="true"`
           - Flag: `<span className="text-base leading-none">🇮🇳</span>`
           - Prefix text: `<span className="font-semibold text-gray-700 tracking-tight text-xs sm:text-sm">+91</span>`
         - Numeric Input:
           - Element: `<input>` with `ref={ref}`, `type="tel"`, `inputMode="numeric"`, `maxLength={10}`, `placeholder="98765 43210"`.
           - Classes: `flex-1 w-full bg-transparent px-3 py-2 text-sm text-gray-900 placeholder:text-gray-400 focus:outline-none disabled:cursor-not-allowed`.
    2. Create `tests/components/phone-input.spec.ts`:
       - Uses Vitest (or `@testing-library/react` if available, or lightweight DOM simulation) to test:
         - Strips initial `+91` from value prop (e.g. passing `"+919876543210"` renders `"9876543210"` in input).
         - Filters non-numeric characters during user typing.
         - Caps input at 10 digits when user types 11+ numbers.
         - Normalizes pasted strings (e.g. pasting `"+91 98765 43210"` produces `"9876543210"`).
         - Emits both 10 subscriber digits and full E.164 string to `onChange`.
  </action>
