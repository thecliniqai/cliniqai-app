## Storage & Gateway Standards

| Option | Description | Selected |
|--------|-------------|----------|
| Standard E.164 (`+919876543210`) | Industry standard worldwide (ITU-T E.164); UI strips +91, gateways strip non-digits to 919876543210 | ✓ |
| Plain 10 digits (`9876543210`) | Prepend +91 dynamically when calling messaging gateways or exports | |
| Country code without plus (`919876543210`) | Direct MSG91 format without leading plus | |

**User's choice:** Worldwide industry standard and gateway expectations (Standard E.164 `+919876543210`).
**Notes:** Stored with `+91` in PostgreSQL. Frontend strips `+91` so user only interacts with 10 digits. Outbound gateways (MSG91/SMS) strip `+` to send `919876543210`.

## Mobile Number Validation Rules

| Option | Description | Selected |
|--------|-------------|----------|
| Strict Indian Mobile | Exactly 10 digits starting with 6, 7, 8, or 9 (`/^[6-9]\d{9}$/`) with instant non-digit filtering on keypress | ✓ |
| Any 10 digits | Exactly 10 numeric digits (`/^\d{10}$/`) without restricting starting digit | |

**User's choice:** Strict Indian Mobile (`/^[6-9]\d{9}$/`).
**Notes:** Rejects invalid lengths or numbers starting with 0-5. Real-time filtering strips non-numeric characters on keystroke/paste and caps length to 10 digits.

## UI Component & Prefix Design

| Option | Description | Selected |

**User's choice:** Reusable `PhoneInput` component.
**Notes:** Designed to match `DESIGN.md` light-only tokens, high contrast focus rings, accessible label association, and smooth copy-paste handling.
