## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Next.js server | Invite creation and membership joins arrive as untrusted input; role and tenant must come from server state |
| Next.js server → Supabase (RLS) | Billing rows and invite rows are gated by RLS as the final boundary |
| invitee → invite token / OTP | The invite token travels via a link; the OTP proves possession of the invited address |
| npm registry → build environment | Phase-wide supply-chain boundary |
