## 3. Security & Anti-Pattern Compliance

- **T-05.1-01 (Parameter Sanitization):** Newlines stripped, whitespace collapsed, Meta length envelopes (1024 body, 60 header, 128 button URL) enforced with deterministic fallback strings.
- **T-05.1-02 (Positional Mapping Mismatch):** Fixed matrix mapping key names to exact positional indexes for all 13 pre-approved templates.
- **T-05.1-03 (API Key Leakage):** Auth key read exclusively server-side from environment; masked in CLI outputs.
- **T-05.1-04 (Webhook Forgery):** Multi-factor signature verification checking `authkey` header, `secret` query parameter, or `x-webhook-secret` header.
- **T-05.1-05 (Accidental Cancellation):** Strict gating: free-text `"2"`, `"no"`, or `"2 days"` routes to conversational triage and NEVER triggers slot release.
- **T-05.1-06 (DLR Retry Loop Hazard):** Permanent delivery failures transition to `dead_letter` and clear `next_retry_at`, stopping infinite outbox retries.
- **PostgreSQL Constraint 000014:97:** Delivery failure and conversational triage notifications strictly use valid category `'system'`.
