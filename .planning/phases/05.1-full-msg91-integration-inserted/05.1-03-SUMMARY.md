## 4. Key Design Decisions & Review Findings Addressed

1. **Pure Sync Engine Extraction (Finding 7):**
   Separated payload generation and status parsing logic into pure functions in `lib/messaging/templates/sync.ts`, decoupling domain logic from CLI file execution and side effects.
2. **`isMain` Guard for Script Importing (Finding 7):**
   Guarded CLI top-level execution in `scripts/msg91-sync-templates.ts` using `process.argv[1] && fileURLToPath(import.meta.url) === path.resolve(process.argv[1])`, allowing test suites and utilities to import `inspectTemplateStatus` and `maskKey` without triggering CLI execution or `process.exit`.
3. **Multi-Envelope Status Parsing:**
   `mapRemoteStatuses` transparently accepts `{ data: [...] }`, `{ data: { templates: [...] } }`, or direct arrays, case-insensitively resolves template names, and initializes unlisted templates to `NOT SUBMITTED`.
4. **Credential Masking in CLI Output (T-05.1-07):**
   Implemented `maskKey` to obscure auth keys in terminal logs (`1234****cdef`), mitigating credentials exposure in terminal scrollback or shared recordings.
