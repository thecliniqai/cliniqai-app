         - `--dry-run`: Preview all 13 template payloads without making HTTP calls.
         - `--status`: Inspect approval status of all templates on MSG91 / Meta.
         - `--authkey=<KEY>`: Override auth key.
         - `--number=<NUM>`: Override integrated WhatsApp number.
       - Implement `inspectTemplateStatus(authKey: string, integratedNumber: string)`:

         - Parse templates using `mapRemoteStatuses` and render output using `formatStatusTable`.
       - Wrap CLI execution in `isMain` guard:
         ```typescript

         import path from "node:path";

         if (process.argv[1] && fileURLToPath(import.meta.url) === path.resolve(process.argv[1])) {
           main().catch((err) => {
             console.error("Error executing template sync:", err);
             process.exit(1);
           });
         }
         ```
