  <action>
    Implement zero-hallucination prescription suggestions and returning patient catch-up:
    1. In `lib/ai/prescription-suggestions.ts`:
       - Function `getDoctorFrequentPrescriptions({ tenantId, doctorId, diagnosis })`:
         - Pure PostgreSQL aggregation over `public.visits` table:
           ```sql
           SELECT 
             item->>'drug_name' AS drug_name,
             item->>'dosage' AS dosage,
             item->>'frequency' AS frequency,
             item->>'duration' AS duration,
             item->>'instructions' AS instructions,
             COUNT(*)::INTEGER AS frequency_count
           FROM public.visits v,
                jsonb_array_elements(v.prescription) AS item
           WHERE v.tenant_id = $1
             AND v.doctor_id = $2
             AND v.diagnosis ILIKE '%' || $3 || '%'
           GROUP BY 1, 2, 3, 4, 5
           ORDER BY frequency_count DESC
           LIMIT 6;
           ```
         - Returns typed list of `PrescriptionSuggestion` items. Zero LLM calls.
    2. In `lib/ai/catch-up-summary.ts`:
       - Function `generatePatientCatchUpSummary({ tenantId, patientId })`:
         - Queries last 3 visits for the patient under the current tenant.
         - If fewer than 1 visit exists, returns `null` ("First visit").
         - Formulates structured prompt to `OpenAiGatewayClient` requesting a 3-bullet clinical brief.
         - Returns `{ last_visit_date, last_diagnosis, active_medications, bullets: string[] }`.
    3. Update `tests/ai/prescription-suggestions.spec.ts` with tests verifying deterministic SQL query execution, grouping by diagnosis, and zero hallucination.
  </action>
