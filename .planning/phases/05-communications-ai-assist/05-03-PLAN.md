<objective>
Build the In-App Notification Center UI, Real-Time Alerts, and Internal Clinic Cues:
1. Create the notification bell component `components/notifications/notification-bell.tsx` with dynamic unread counter badge and integrate it into `components/layout/app-header.tsx` left of `UserDropdown`.
2. Build the slide-over notification drawer `components/notifications/notification-drawer.tsx` (400px width, right slide animation, ESC / backdrop dismiss, tabs: `All`, `Clinical`, `Queue`, `Billing`, "Mark all as read" button, empty state, and 1-click navigation links).
3. Implement Server Actions in `features/notifications/actions.ts` for listing, marking as read, and bulk dismissals with strict tenant RLS.
4. Implement trigger helpers in `features/notifications/triggers.ts` for all 11 internal clinic cues:
   - Events 13–16: Patient Checked-In, Vitals Recorded, Lab Report Ready, Schedule Conflict (Doctor).
   - Events 17–19: Waitlist Slot Freed, Inbound WhatsApp Reply, No-Show Alert (Front Desk).
   - Events 20–23: Staff Invite Accepted, Monthly Quota Warning, End-of-Day Digest, Outbox Failure (Owner/Admin).
5. Verify in-app notification tests pass.
</objective>
