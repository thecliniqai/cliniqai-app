<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → /api/v1/* | Untrusted external network traffic crossing into ClinicQ API layer |
| API Route Handler → Supabase Postgres | Tenant boundary enforced via derived session.tenantId and RLS |
| In-Memory Rate Limiter → Route Handler | Enforces resource quota before database queries |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Spoofing | /api/v1/* auth middleware | high | mitigate | Bearer tokens require clq_live_ prefix, lookup via key_prefix index, and SHA-256 hash matching in lib/api/auth.ts |
| T-06-02 | Information Disclosure | lib/api/auth.ts token comparison | medium | mitigate | Timing side-channel defeated using crypto.timingSafeEqual on equal-length SHA-256 digest buffers |
| T-06-03 | Denial of Service | /api/v1/* endpoints | high | mitigate | Sliding window rate limiting in lib/api/rate-limiter.ts enforcing 120 req/min per key with standard 429 response |
| T-06-SC | Tampering | npm dependencies | high | mitigate | Zero new npm packages added; uses Node.js native crypto and existing tested project dependencies |
</threat_model>
