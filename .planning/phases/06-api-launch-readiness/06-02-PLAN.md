## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External API Request → Clinical Mutation Route | Caller attempts to issue medical records or write clinical notes |
| Clinical Mutation Route → Doctor Guard Middleware | Enforces physician role validation against clinic memberships |
| API Route Handler → Supabase Postgres | Tenant boundary enforced via derived session.tenantId |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04 | Elevation of Privilege | /api/v1/visits & /api/v1/prescriptions | high | mitigate | Doctor Guard middleware (lib/api/doctor-guard.ts) validates doctor_id belongs to tenant and holds role doctor or owner |
| T-06-05 | Information Disclosure | /api/v1/prescriptions & /api/v1/visits | high | mitigate | Tenant isolation enforced in all database queries using session.tenantId, preventing cross-tenant medical record disclosure |

</threat_model>
