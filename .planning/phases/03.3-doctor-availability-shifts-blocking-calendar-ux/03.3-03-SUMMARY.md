# Plan 03.3-03 Summary: Calendar Timeline, Dynamic Shifts & Scheduling UX

## Overview
Upgraded the Calendar View and Doctor Timeline with interactive multi-doctor filter pills, dynamic start/end hour boundaries computed from active doctor shifts, off-duty break dimming, diagonal hatching for schedule blocks, multi-slot ongoing appointment cards, a Soft-Block Emergency Override Dialog, and doctor-preferred slot duration auto-population in Booking & Walk-In Drawers.

## Deliverables
1. **Interactive Doctor Filter Pills (`components/calendar/calendar-view.tsx`)**:
   - Horizontal pill bar offering `All Doctors (N)` and per-doctor toggle pills with status indicator, doctor name, and specialty tag.
   - Single-click filtering to individual doctor, and multi-select support (Shift/Cmd-click) for side-by-side doctor schedule comparisons.
   - Secondary action `[ + Block Time ]` button in the calendar toolbar opening `BlockTimeModal`.
2. **Dynamic Doctor Timeline (`components/calendar/doctor-timeline.tsx`)**:
   - Dynamically computes earliest start hour and latest end hour based on visible doctors' working shifts for the current date (e.g. 08:00 to 21:30) rather than a rigid 9-to-6 window.
   - Renders off-duty periods (such as afternoon breaks between morning and evening shifts) with dimmed styling and an "Off Duty" label.
   - Renders active doctor and clinic-wide schedule blocks with diagonal hatching pattern, amber badge, and block reason.
   - Renders ongoing multi-slot appointments with connected continuation indicators (`↳ Patient (in progress) • 45m`) preventing accidental overlap bookings.
3. **Soft-Block Emergency Override Dialog (`components/calendar/soft-block-override-dialog.tsx`)**:
   - Warns staff when clicking an off-duty or blocked slot that the doctor is unavailable.
   - Requires an explicit emergency justification note before allowing an override.
   - Automatically pre-fills the Booking Drawer with `[EMERGENCY OVERRIDE]` reason, sets `is_overbooked: true`, and applies `override_off_duty` / `override_block` flags.
4. **Booking Drawer & Walk-In Drawer Updates (`booking-drawer.tsx`, `walk-in-drawer.tsx`)**:
   - Clean doctor name resolution with specialty labels and zero UUID fragments.
   - Auto-sets appointment duration dropdown to the selected doctor's default slot duration (e.g. 45m for Dentist, 15m for General Physician).
   - Expanded duration options (15m, 20m, 30m, 45m, 60m, 90m).
5. **Integration Tests (`tests/integration/calendar-scheduling-ux.spec.ts`)**:
   - 9 integration tests covering clean doctor name formatting, dynamic shift matching, off-duty afternoon break detection, multi-slot 45m overlap prevention, off-duty rejection without override, emergency override acceptance with audit logging, and schedule block override.
   - 100% tests passing.
