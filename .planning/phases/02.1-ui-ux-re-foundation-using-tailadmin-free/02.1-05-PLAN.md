# Plan 02.1-05: Team, Settings, Auth & Responsive/Visual Verification

**Phase:** 02.1 (Phase 2B) — UI/UX Re-foundation Using TailAdmin Free  
**Plan:** 05 of 05  
**Type:** Administrative Screens & Quality Gate Verification  

## Goal
Redesign the remaining administrative interfaces (Staff management, Clinic Profile, Subscription & Billing), review auth/onboarding screens, execute comprehensive responsive visual inspection across desktop and mobile, and verify build/test suites.

## Detailed Tasks

### 1. Staff & Team Management (`app/(dashboard)/staff/page.tsx`)
- Header: Title, description, staff count badge.
- Invite Staff Form Card:
  - Input field for email, select dropdown for assigned role (`Doctor`, `Receptionist`, `Nurse`, `Admin`), "Send Invitation" button.
- Active Members Table:
  - TailAdmin `Table` showing User Identifier, Joined Date, and Role Badge.
- Pending Invitations Table:
  - TailAdmin `Table` showing Invited Address, Expiration Date, Role Badge, and status.

### 2. Clinic Profile & Billing Settings (`app/(dashboard)/settings/*`)
- **Clinic Profile (`app/(dashboard)/settings/clinic/page.tsx`):**
  - Clinic identity card: Name input, physical address input, operational timezone input.
  - Practice Specialties: Grid of checkboxes styled with TailAdmin custom checkboxes.
  - Primary "Save Changes" button.
- **Subscription & Billing (`app/(dashboard)/settings/billing/page.tsx`):**
  - Current Subscription Card: Plan name, monthly amount in INR (tabular figures), active status badge, renewal date.
  - Payment History Table: Receipt date, payment method badge (UPI, Card, Cash), amount, reference ID, "Paid" status badge.

### 3. Authentication & Onboarding Screens (`app/(auth)/*`, `app/(onboarding)/*`)
- **Login (`app/(auth)/login/page.tsx`):**
  - TailAdmin centered card with clean typography, email input, OTP request button.
- **Verify OTP (`app/(auth)/verify/page.tsx`):**
  - 6-digit OTP code input, countdown timer, resend button.
- **Join Clinic (`app/(auth)/join/page.tsx`):**
  - Invitation acceptance card with clinic name and role confirmation.
- **Clinic Onboarding (`app/(onboarding)/clinic/new/page.tsx`):**
  - Step indicator ("Step 1 of 2"), clinic name input, "Create Clinic" button.

### 4. Responsive & Visual Verification
- **Screen Viewport Inspection:**
  - Desktop (1280px / 1440px): Sidebar expanded, multi-column dashboard, tabular views.
  - Tablet (768px - 1024px): Sidebar collapsed to icon mode or drawer, adjusted gutters.
  - Mobile (375px / 390px): Sidebar hidden with hamburger trigger and backdrop drawer; tables convert to cards or horizontal scroll; 44px min touch targets verified; no horizontal viewport spill.
- **Code & Test Quality Gates:**
  - `npm run typecheck` passes with zero errors.
  - `npm run build` succeeds without compiler warnings or errors.
  - `npm run test` executes cleanly.
  - Documentation update: Update `DESIGN.md` with TailAdmin tokens, component specifications, and design system harmonization.

## Verification
- Next.js production build (`npm run build`) completes successfully.
