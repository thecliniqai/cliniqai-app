# Plan 02.1-04: Doctor Calendar & Live Queue Redesign

**Phase:** 02.1 (Phase 2B) — UI/UX Re-foundation Using TailAdmin Free  
**Plan:** 04 of 05  
**Type:** Core Clinical Workflow Redesign  

## Goal
Redesign the Front Desk scheduling calendar (doctor day timeline, booking drawer, waitlist drawer, overbooking dialog) and live reception queue (unified tokens, status actions, walk-in drawer) with the TailAdmin design system.

## Detailed Tasks

### 1. Doctor Timeline Calendar (`app/(dashboard)/calendar/page.tsx` & `components/calendar/*`)
- **Calendar Header Controls:**
  - Date Navigator: Previous day button, "Today" button, Next day button, and formatted calendar display (`Tuesday, 8 Oct 2026`).
  - Action Buttons: "New Appointment" primary button and "Waitlist (N)" badge button with active count chip.
  - Auto-promotion notification banner: Clean emerald alert when a waitlisted patient is auto-promoted into a cancelled slot.
- **Timeline Grid (`components/calendar/doctor-timeline.tsx`):**
  - Columns per active doctor with professional doctor header chip (avatar, name, role badge).
  - Time gutter (e.g. 09:00, 09:30, 10:00 ... 18:00) with subtle hairline dividers.
  - Time Slot Cells:
    - Empty slots: Clean hover indicator with "+" affordance for 1-tap booking.
    - Booked slots: Styled visit cards showing Patient Name, Time, Appointment Type (`scheduled` vs `walk_in`), and Status Badge (`Waiting`, `In Consultation`, `Completed`).
    - Cancel action with confirmation.
- **Booking Drawer (`components/calendar/booking-drawer.tsx`):**
  - TailAdmin slide-over drawer panel (desktop right drawer, mobile bottom sheet).
  - Patient search dropdown / quick-select.
  - Doctor select, appointment date picker, time slot select, appointment type radio pills.
  - Overbooking safeguard trigger.
- **Waitlist Drawer (`components/calendar/waitlist-drawer.tsx`):**
  - Slide-over drawer listing all active waitlisted patients for the selected date.
  - Priority indicator, patient contact, requested doctor, and "Add to Waitlist" form.
- **Overbook Dialog (`components/calendar/overbook-dialog.tsx`):**
  - TailAdmin modal dialog with warning icon: *"Slot already booked by [Patient]. Overbook this slot?"*.
  - Explicit confirmation and cancel buttons.

### 2. Live Reception Queue (`app/(dashboard)/queue/page.tsx` & `components/queue/*`)
- **Queue Control Header:**
  - Date navigator matching calendar style.
  - Doctor filter dropdown (`All Doctors`, or specific doctor).
  - "Check-in Walk-in" primary action button.
- **Queue Metrics Bar:**
  - Summary cards/pills:
    - Total Checked In
    - Waiting (amber badge)
    - In Consultation (blue badge)
    - Completed (emerald badge)
- **Live Queue List / Cards (`components/queue/queue-view.tsx` & `queue-card.tsx`):**
  - Token Chip: Large high-contrast token indicator (`#1`, `#2`, `#3` or `#A-01`).
  - Patient Details: Full name, phone, appointment type tag (`Walk-in` vs `Scheduled @ 10:30 AM`).
  - Wait time counter and assigned doctor chip.
  - Status progression buttons:
    - When `Waiting`: "Call In" / "Start Consultation" (primary button).
    - When `In Consultation`: "Complete Visit" (emerald button).
    - Terminal states: "No Show" or "Cancel" in secondary overflow menu.
- **Walk-in Drawer (`components/queue/walk-in-drawer.tsx`):**
  - Slide-over drawer for fast front-desk intake:
    - Search existing patient or quick register name/phone.
    - Assign doctor.
    - Chief complaint / visit notes (optional).
    - 1-tap "Generate Token & Check In".

## Verification
- Calendar displays time slots and doctor columns accurately.
- Booking drawer opens, creates appointments, and renders them in the timeline.
- Overbooking prompt triggers when booking a conflicting slot and succeeds when confirmed.
- Queue displays both scheduled and walk-in arrivals with correct daily tokens.
- Status transitions ("Waiting" -> "In Consultation" -> "Completed") update live state cleanly.
- Drawers and dialogs render responsively on mobile and desktop.
