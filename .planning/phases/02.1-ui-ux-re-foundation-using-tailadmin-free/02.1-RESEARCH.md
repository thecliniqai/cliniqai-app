## 2. Key TailAdmin Component Patterns to Adapt

### 2.1 Layout Shell (`components/layout/`)
1. **`SidebarContext.tsx`**: Provides `isExpanded`, `isMobileOpen`, `toggleSidebar()`, `toggleMobileSidebar()`. Auto-closes on mobile route change (`usePathname()`) and window resize (`< 768px`).
2. **`AppSidebar.tsx`**:
   - Desktop: fixed `w-72.5` (290px) when expanded, `w-22.5` (90px) when collapsed.
   - Mobile: off-canvas drawer (`-translate-x-full` default, `translate-x-0` when open) with high z-index (`z-50`).
   - Grouped navigation links with active pill states (`bg-brand-50 text-brand-600 font-medium`).
3. **`AppHeader.tsx`**: Sticky top bar (`h-16`) containing mobile menu trigger, clinic identifier, role badge, global search input (`Cmd+K`), and user profile menu.
4. **`Backdrop.tsx`**: Fixed overlay (`bg-gray-900/50 backdrop-blur-xs`) rendered on mobile when sidebar is open; clicking closes sidebar.

### 2.2 Reusable UI Primitives (`components/ui/`)
1. **`button.tsx`**:
   - Variants: `primary` (brand blue with hover/active), `secondary` / `outline` (white card with border), `ghost`, `danger`.
   - Sizes: `sm` (36px), `md` (44px min touch target), `lg` (48px).
   - Features: `startIcon`, `endIcon`, `loading` spinner.
2. **`input.tsx` & `field.tsx`**:
   - Inputs styled with `h-11 rounded-lg border border-gray-300 text-gray-800 placeholder-gray-400 focus:border-brand-500 focus:ring-3 focus:ring-brand-500/15`.
   - Accessible label, required asterisk, inline help text, error message with `id` linkage.
3. **`card.tsx` / `ComponentCard.tsx`**:
   - Clean container: `rounded-xl border border-gray-200 bg-white shadow-theme-xs`.
   - Header with title, subtitle/meta, optional right-side action slot, border-t divider to card body.
4. **`table.tsx`**:
   - Modular semantic table: `<Table>`, `<TableHeader>`, `<TableBody>`, `<TableRow>`, `<TableCell>`, `<TableHead>`.
   - Header: `bg-gray-50 text-xs font-semibold uppercase text-gray-500 px-4 py-3`.
   - Rows: `hover:bg-gray-50/75 transition-colors border-b border-gray-100 text-sm text-gray-800`.
5. **`badge.tsx`**:
   - Status badges with light and solid variants:
     - Neutral (`bg-gray-100 text-gray-700`)
     - Success / Completed (`bg-emerald-50 text-emerald-700 border-emerald-200`)
     - Warning / Waiting (`bg-amber-50 text-amber-700 border-amber-200`)
     - Error / Cancelled (`bg-rose-50 text-rose-700 border-rose-200`)
     - Info / In Consultation (`bg-blue-50 text-blue-700 border-blue-200`)
     - ABDM / ABHA badge (`bg-emerald-50 text-emerald-800 font-medium`)
6. **`modal.tsx` / `dialog.tsx`**:
   - Accessible dialog with backdrop blur, centered panel, title, close button, and focus retention.
7. **`dropdown.tsx`**:
   - Popover menu with click-outside dismissal (`useClickOutside`), trigger slot, item list.
8. **`alert.tsx`**:
   - Inline alert notification with icon and dismiss action.
9. **`empty-state.tsx`**:
   - Centered icon, title, description, and primary CTA for empty directories/queues.

## 3. Dependency Differences & Resolution

1. **Current Dependencies**:
   - `@supabase/ssr`, `@supabase/supabase-js`, `lucide-react`, `next@15.2.1`, `react@19.0.0`, `react-dom@19.0.0`, `zod`.
2. **Dependencies to Add**:
   - `clsx`: lightweight className concatenation.
   - `tailwind-merge`: resolves Tailwind class conflicts in composite components.
   - Run: `npm install clsx tailwind-merge`
3. **Dependencies to Avoid**:
   - Do NOT install `next-intl` (we are not introducing multi-language routing).
   - Do NOT install `@fullcalendar` or `swiper` (our custom doctor timeline and walk-in drawers are cleaner and lighter).
   - Do NOT install `@react-jvectormap`.
4. **TypeScript Configuration Adjustment**:
   - Add `"docs"` to `"exclude"` in `tsconfig.json` to prevent TypeScript from validating external reference code in `docs/temp/free-nextjs-admin-dashboard-main/`.

## 4. Risks & Mitigations

1. **Risk: Breaking existing server actions or Supabase RLS during UI restructuring.**
   - *Mitigation:* Pure visual refactoring. Form `onSubmit` and `action` handlers remain bound to the existing `features/*/actions.ts`. No server action signatures or data contracts will be modified.
2. **Risk: Mobile responsiveness regression.**
   - *Mitigation:* Design mobile-first. Validate 375px viewport with off-canvas sidebar drawer, horizontal table scrolling or responsive card transformations, and 44px minimum touch targets.
3. **Risk: Inconsistent design system drift.**
   - *Mitigation:* Centralize all styling tokens in `app/globals.css` and all visual primitives in `components/ui/` and `components/layout/`. Reusable primitives will be strictly mandated across all pages.
