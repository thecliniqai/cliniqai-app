<objective>
Build the data layer, terminology foundations, and drug master architecture for Phase 3:
1. Migration `000007_consultation_prescriptions_cdci.sql` extending `visits` with SOAP & specialty columns, creating `consultation_diagnoses`, `prescriptions`, `prescription_items`, `doctor_custom_medicines`, `doctor_custom_diagnoses`, `doctor_prescription_templates`, `visit_revisions`, `follow_ups`, and central CDCI tables (`cdci_medicines_search`) with pg_trgm GIN indexes and RLS.
2. High-performance streaming CDCI TSV ingestion pipeline (`scripts/seed-cdci.ts`) and fast test fixture (~200 drugs in `scripts/seed-cdci-test-fixture.ts`).
3. Curated Indian OPD terminology dataset (`supabase/seed-data/terminology/diagnoses.json`) with ~1,500 ICD-11 and SNOMED CT concepts and loader (`scripts/seed-opd-diagnoses.ts`).
4. Vitest integration test suite proving sub-100ms drug search RPC, doctor favorite prioritization, and strict multi-tenant isolation.
</objective>

<threat_model>
| Threat ID | Category | Component | Description | Severity | Mitigation |
|-----------|----------|-----------|-------------|----------|------------|
| T-03-01 | Information Disclosure / Injection | `search_medicines` & `search_diagnoses` RPCs | Malicious search query or SQL injection could leak cross-tenant doctor custom medicines or bypass tenant filters. | high | Use parameterized PL/pgSQL queries with strict `SET search_path = public`, tenant boundary checks (`cm.tenant_id = p_tenant_id AND cm.doctor_id = p_doctor_id`), and RLS on underlying tables. |
| T-03-02 | Broken Access Control / Data Tampering | Tenant-owned consultation tables | Unauthorized tenant attempting to read, insert, update, or delete diagnoses, prescriptions, or revisions of another clinic. | high | Enforce Row Level Security on all 8 tenant-owned tables using `tenant_id IN (SELECT public.current_user_tenant_ids())`. Child tables verify parent tenant ownership. |
</threat_model>

       - `id UUID PK`, `tenant_id UUID FK`, `doctor_id UUID FK`, `diagnosis_name TEXT`, `specialty TEXT`, `use_count INTEGER DEFAULT 1`, `created_at`, `updated_at`. Unique `(tenant_id, doctor_id, diagnosis_name)`.
    7. Create `doctor_prescription_templates`:
       - `id UUID PK`, `tenant_id UUID FK`, `doctor_id UUID FK`, `template_name TEXT`, `specialty TEXT`, `items JSONB`, `created_at`, `updated_at`.
    8. Create `visit_revisions`:
       - `id UUID PK`, `tenant_id UUID FK`, `visit_id UUID FK`, `revision_number INTEGER`, `amended_by UUID FK auth.users(id)`, `amended_at TIMESTAMPTZ DEFAULT now()`, `amendment_reason TEXT NOT NULL`, `snapshot JSONB NOT NULL`. Unique `(visit_id, revision_number)`.
    9. Create `follow_ups`:
       - `id UUID PK`, `tenant_id UUID FK`, `patient_id UUID FK`, `visit_id UUID FK`, `doctor_id UUID FK`, `follow_up_date DATE NOT NULL`, `notes TEXT`, `status TEXT DEFAULT 'scheduled' CHECK (status IN ('scheduled', 'attended', 'cancelled', 'missed'))`, `created_at`.
    10. Alter `public.tenants` & `public.memberships`:
       - Tenants: `logo_url TEXT`, `phone TEXT`, `email TEXT`, `registration_number TEXT`, `letterhead_top_margin INTEGER DEFAULT 110`, `letterhead_bottom_margin INTEGER DEFAULT 60`.
       - Memberships: `qualifications TEXT`, `medical_council_reg_no TEXT`, `signature_url TEXT`, `default_specialty TEXT DEFAULT 'general_physician'`.
    11. Central CDCI Tables:
       - Enable `pg_trgm` extension.
       - Tables: `cdci_substances`, `cdci_drug_forms`, `cdci_routes`, `cdci_suppliers`, `cdci_products`, `cdci_generics`, `cdci_brands`.
       - Denormalized search table `cdci_medicines_search` with columns `(id, brand_name, product_name, generic_name, dose_form, route, supplier_name, search_vector tsvector)`.
       - GIN trigram indexes on `brand_name gin_trgm_ops`, `generic_name gin_trgm_ops`, and GIN on `search_vector`.
    12. Central Terminology:
       - Table `opd_diagnoses` (`id UUID PK`, `name TEXT`, `icd11_code TEXT`, `snomed_concept_id TEXT`, `category TEXT`, `specialties TEXT[]`, `is_chronic BOOLEAN DEFAULT false`, `synonyms TEXT[]`).
       - GIN trigram index on `name gin_trgm_ops` and GIN index on `specialties`.
    13. RPC `search_medicines(p_query TEXT, p_doctor_id UUID, p_tenant_id UUID, p_limit INTEGER)`:
       - Returns union of doctor favorites and CDCI master drugs sorted by `is_favorite DESC, medicine_name ASC`.
    14. Enable RLS and define tenant-isolation policies on all 8 tenant tables using `tenant_id IN (SELECT public.current_user_tenant_ids())`. Grant read-only access to `cdci_*` and `opd_diagnoses` to `authenticated`.

       - Extend `Visit` interface with vitals, complaints, specialty, and revision fields.
