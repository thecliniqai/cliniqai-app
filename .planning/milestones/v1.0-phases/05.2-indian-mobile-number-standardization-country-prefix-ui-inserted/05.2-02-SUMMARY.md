## 4. Key Design Decisions & Deviations

1. **Prefix-Aware Paste Normalization (`normalizePastedPhone`):** In `components/ui/phone-input.tsx`, `normalizePastedPhone` handles pasted clipboard text containing prefixes (`+91`, `91`, or `0`) before taking the first 10 digits. When pasting 10-digit numbers starting with `91` (e.g. `9123456789`), it preserves the number as-is without stripping valid subscriber digits.
2. **Pure TypeScript Component Testing via `renderToStaticMarkup`:** Because the test environment uses Vitest in Node mode (`environment: "node"` without JSDOM), `tests/components/phone-input.spec.ts` leverages `React.createElement` and `renderToStaticMarkup` from `react-dom/server` alongside isolated unit testing of change and paste handlers, achieving 100% test coverage with zero native DOM dependencies.
3. **Clean Container Inset Icon Replacement:** In `edit-staff-modal.tsx`, `clinic-profile-form.tsx`, and `user-profile-form.tsx`, the legacy `<div className="relative"><span className="absolute start-3"><Phone /></span><Input className="ps-9" /></div>` construct was removed in favor of `<PhoneInput />`, eliminating duplicate icon noise and providing a unified badge appearance throughout the app.
