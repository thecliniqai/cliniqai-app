## Component Specification: `PhoneInput`

### 1. Visual Layout & DOM Structure
```text
┌─────────────────────────────────────────────────────────────────┐
│ ┌──────────────┬───┬──────────────────────────────────────────┐ │
│ │ 🇮🇳  +91      │ │ │ 98765 43210                              │ │
│ └──────────────┴───┴──────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```
- **Wrapper Container:** `relative flex items-center w-full rounded-md border border-gray-300 bg-white transition-colors`
- **Focus State:** `focus-within:border-[#1769E0] focus-within:ring-2 focus-within:ring-[#1769E0]/20`
- **Error State:** `border-red-500 focus-within:border-red-500 focus-within:ring-red-500/20`
- **Disabled State:** `bg-gray-50 opacity-60 cursor-not-allowed`
- **Prefix Badge:**
  - Inset left-side container: `flex items-center gap-1.5 px-3 py-2 select-none border-r border-gray-200 bg-gray-50/80 rounded-l-md text-gray-700 font-medium text-sm`
  - Flag icon: Unicode emoji `🇮🇳` (16px) or SVG inline flag
  - Prefix text: `+91` (`text-sm font-semibold text-gray-700 tracking-tight`)
- **Interactive Input:**
  - Element: `<input type="tel" inputMode="numeric" />`
  - Classes: `flex-1 w-full bg-transparent px-3 py-2 text-sm text-gray-900 placeholder:text-gray-400 focus:outline-none`
  - Height & Touch Target: Min 40px on desktop (`h-10`), Min 44px on mobile (`h-11`)
  - Placeholder: `"98765 43210"` or `"9876543210"`

### 2. Interaction & Formatting Contract
- **Digit Filtering:** On change/keypress, all non-digit characters (`\D`) are instantly stripped:
  ```typescript
  const cleanDigits = raw.replace(/\D/g, "").slice(0, 10);
  ```
- **Copy-Paste Normalization:** If a user pastes `+91 98765 43210`, `09876543210`, or `919876543210`:
  - Strips leading `+91`, `91`, or `0` if total digits are 11 or 12.
  - Takes the last 10 digits starting with `[6-9]`.
- **Display vs Persistence:**
  - Input field renders strictly the 10 digits (`9876543210`).
  - Emits normalized E.164 (`+919876543210`) to form handlers and database models.

## Accessibility Contract (WCAG 2.2 AA)

- **Semantic Label Association:** `<PhoneInput id="phone">` associates with `<label htmlFor="phone">` via `id`.
- **Keyboard Navigation:** Tab order navigates directly into the input. The `🇮🇳 +91` badge is non-interactive (`aria-hidden="true"` or label adornment) so users don't waste tab stops.
- **Screen Reader Announcements:** `<input aria-label="10-digit Indian mobile number" aria-describedby="phone-error phone-help">`.
- **Mobile Keyboards:** `type="tel"` and `inputMode="numeric"` trigger the dedicated numeric telephone keypad on iOS and Android.
