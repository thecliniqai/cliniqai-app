## 4. Threat Model & Security Verification

| Threat ID | STRIDE Category | Component | Mitigation Verification | Status |
|-----------|-----------------|-----------|-------------------------|--------|
| **T-05.2-01** | Tampering / Injection | `features/patients/schema.ts` | `extractTenDigits` strips non-digits; `INDIAN_MOBILE_REGEX` rejects non-mobile prefixes (0–5); `toE164` transforms valid numbers to safe `+91XXXXXXXXXX`. | **MITIGATED** |
| **T-05.2-02** | Integrity Loss | `supabase/migrations/000017_normalize_indian_phone_numbers.sql` | `normalize_indian_phone_e164()` skips already-normalized `+91%` strings, validates 10 digits starting with `[6-9]`, and falls back to trimmed original string if length is non-standard. | **MITIGATED** |
| **T-05.2-03** | Repudiation / Duplicate Bypass | `features/patients/dedup.ts` | Deduplication normalizes all phone inputs through `toE164` before executing tenant-scoped query, guaranteeing exact matching against stored E.164 phone numbers. | **MITIGATED** |
| **T-05.2-04** | Tampering / Malformed Input | `components/ui/phone-input.tsx` | `handlePaste` intercepts clipboard events, executes `normalizePastedPhone` to strip prefixes (`+91`, `91`, `0`), and retains strictly the 10 subscriber digits. | **MITIGATED** |
| **T-05.2-05** | State Desynchronization | Form Drawers and Modals | `PhoneInput` uses `useEffect` to synchronize internal `digits` state when `value` prop changes; drawers reset form state on close. | **MITIGATED** |
| **T-05.2-06** | Accessibility Exclusion | `components/ui/phone-input.tsx` | Prefix badge is marked `aria-hidden="true"`, input maintains `type="tel"` and `inputMode="numeric"` for mobile dial pad popup, and wrapper uses `focus-within:ring-[#1769E0]` for WCAG 2.2 AA compliant focus indication. | **MITIGATED** |
| **T-05.2-07** | Tampering / Injection | `features/patients/actions.ts` & `features/visits/actions.ts` | Query sanitizer strips PostgREST delimiters `,`, `(`, and `)` (`clean.replace(/[,()]/g, " ")`), extracts alphanumeric/digit tokens safely, and bounds queries. | **MITIGATED** |
| **T-05.2-08** | Information Disclosure | `features/patients/actions.ts` & `features/visits/actions.ts` | All database queries strictly enforce `.eq("tenant_id", session.tenantId)` at database query level before applying search OR clause; verified by Supabase Row-Level Security (RLS). | **MITIGATED** |
| **T-05.2-09** | Denial of Service | `features/patients/actions.ts` & `features/visits/actions.ts` | Minimum digit threshold (>= 3 digits) required for numeric phone search expansion; queries capped with `.limit(25)` / `.limit(100)`. | **MITIGATED** |
