# Plan 02.1-03: Dashboard & Patient Management Redesign

**Phase:** 02.1 (Phase 2B) — UI/UX Re-foundation Using TailAdmin Free  
**Plan:** 03 of 05  
**Type:** Core Domain Screen Redesign  

## Goal
Redesign the primary clinic dashboard overview and all patient-related screens (Directory, Registration with duplicate detection and age/DOB sync, and Patient Record Detail) using the new TailAdmin component system while strictly preserving existing business rules and server actions.

## Detailed Tasks

### 1. Dashboard Overview (`app/(dashboard)/page.tsx`)
- Transform the crude 3-box placeholder into a polished TailAdmin clinic operations cockpit:
  - **Header Banner:** Clinic welcome greeting, date display, active doctor/staff status.
  - **Operations Metric Cards:**
    - Live Queue: Count of waiting patients, avg wait time indicator, link to `/queue`.
    - Appointments: Today's scheduled visits count, next upcoming visit, link to `/calendar`.
    - Registered Patients: Total patient records count, new registrations this week, link to `/patients`.
  - **Quick Action Bar:** 1-tap buttons for high-frequency actions:
    - "Register New Patient" (primary brand button)
    - "Book Appointment" (secondary outline button)
    - "Check-in Walk-in" (secondary outline button)
  - **Live Overview Table:** TailAdmin table showing the top 5 queue/visit records for today with status badges and quick action links.

### 2. Patient Directory (`app/(dashboard)/patients/page.tsx`)
- Modernize the patient list into a professional healthcare directory:
  - **Header Section:** Page title, count badge ("24 Patients Registered"), search bar with debounce, and "Register Patient" primary action button.
  - **Data Table:** Using `Table`, `TableHeader`, `TableRow`, `TableCell`:
    - Columns: Patient Name, Phone Number, Age / Gender, ABDM / ABHA ID, Registration Date, Actions.
    - Status & Identity Badges: Clean emerald badge for verified ABHA IDs, subtle pills for gender.
    - Hover row highlights, responsive tabular view on desktop.
    - Mobile Card View: Stacked card format for screens < 640px to prevent horizontal overflow.
  - **Empty State:** TailAdmin `EmptyState` component with user icon, clear explanatory copy, and "Register First Patient" button.

### 3. Patient Registration (`app/(dashboard)/patients/new/page.tsx`)
- Restructure the registration form using TailAdmin `Card` sections:
  - **Card 1: Basic Demographics:** Full name input, 10-digit phone number input, Sex select.
  - **Card 2: Age & Date of Birth Sync (`components/patients/age-dob-input.tsx`):**
    - Refactor `AgeDobInput` using TailAdmin input styles while preserving the bidirectional sync logic (entering DOB computes age; entering age computes Jan 1 DOB).
  - **Card 3: National Health Identity (ABDM):** ABHA ID / address input with ABDM badge and clear optional guidance.
  - **Card 4: Address Information:** Address line 1 and responsive 3-column grid for City, State, and Pincode.
  - **Duplicate Warning Banner (`components/patients/duplicate-warning-banner.tsx`):**
    - Redesign with TailAdmin alert styling: amber warning surface, icon, matching patient details chip, and dual actions ("View Existing Record" vs "Dismiss & Proceed").
  - Form actions: "Cancel" (secondary) and "Register Patient" (primary brand button with loading spinner).

### 4. Patient Detail Page (`app/(dashboard)/patients/[id]/page.tsx`)
- Redesign the patient record view:
  - **Header Card:**
    - Back button link to `/patients`.
    - Patient avatar/initials bubble, full name, phone number, and ABHA status badge.
    - Quick actions: "Book Appointment", "Add to Queue".
  - **Grid Layout (2-column on desktop):**
    - **Left Column (Demographics & Medical Record Info):**
      - Clean key-value presentation for DOB, Age, Gender, Address.
      - Creation timestamp and audit log badge.
    - **Right Column (Consent & Compliance History):**
      - Redesign `ConsentSection` with TailAdmin toggle/switch cards showing Treatment Consent and Data Sharing Consent states with immutable audit timestamps.

## Verification
- Patient registration submits successfully and redirects to patient detail page.
- Duplicate detection warning banner triggers correctly on matching phone/name and looks visually polished.
- Age/DOB dual-sync operates accurately in both directions.
- All patient directory search, pagination, and detail views render cleanly on both desktop (1280px) and mobile (375px).
