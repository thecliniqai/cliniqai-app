# Plan 02.1-02: TailAdmin Application Shell & Navigation

**Phase:** 02.1 (Phase 2B) — UI/UX Re-foundation Using TailAdmin Free  
**Plan:** 02 of 05  
**Type:** Layout & Navigation Infrastructure  

## Goal
Build the TailAdmin-inspired responsive application shell consisting of the collapsible desktop sidebar, mobile overlay drawer, backdrop, top header with user profile menu, and integrated layout wrapper.

## Detailed Tasks

### 1. Sidebar State Context (`components/layout/sidebar-context.tsx`)
- Implement `SidebarContext` and `SidebarProvider`:
  - Manage state: `isExpanded` (boolean, default true on desktop), `isMobileOpen` (boolean, default false), `isHovered` (boolean).
  - Actions: `toggleSidebar`, `toggleMobileSidebar`, `closeMobileSidebar`.
  - Listen for route transitions (`usePathname()`) and auto-close mobile sidebar.
  - Listen for window resize and adapt responsive thresholds (`< 768px` vs `>= 1280px`).

### 2. TailAdmin Sidebar (`components/layout/app-sidebar.tsx`)
- Adapt TailAdmin's `AppSidebar` pattern to clinicOS:
  - Desktop: fixed `w-72.5` (290px) when expanded, `w-22.5` (90px) when collapsed, smooth transition.
  - Mobile: off-canvas drawer (`-translate-x-full` default, `translate-x-0` when open) with `z-50`.
  - Clinic identity header:
    - Clinic brand logo icon / initials badge ("CQ") + Clinic Tenant Name.
    - Role pill badge (`owner`, `doctor`, `admin`, etc.).
  - Navigation Sections:
    - **Clinical Operations:**
      - Dashboard (`/` — LayoutDashboard)
      - Live Queue (`/queue` — Clock / Users)
      - Appointments & Calendar (`/calendar` — Calendar)
      - Patient Directory (`/patients` — Users)
    - **Management (Role-guarded: Owner/Admin only):**
      - Staff & Team (`/staff` — UserCheck)
      - Clinic Profile (`/settings/clinic` — Building2)
      - Subscription & Billing (`/settings/billing` — CreditCard)
  - Active item styling:
    - `bg-brand-50 text-brand-600 font-semibold` with brand-colored icon.
  - Inactive item styling:
    - `text-gray-600 hover:bg-gray-100 hover:text-gray-900 transition-colors`.

### 3. TailAdmin Header (`components/layout/app-header.tsx`)
- Adapt TailAdmin's `AppHeader` pattern to clinicOS:
  - Sticky top bar (`h-16 border-b border-gray-200 bg-white`).
  - Left side:
    - Mobile menu hamburger button (`toggleMobileSidebar`).
    - Desktop sidebar expand/collapse button.
    - Breadcrumbs / Context label (e.g. "Front Desk Console").
  - Center:
    - Search shortcut input (`Cmd+K` keyboard shortcut trigger).
  - Right side:
    - Quick notifications placeholder.
    - User Profile Dropdown (`components/layout/user-dropdown.tsx`):
      - Avatar / initials chip.
      - User email & active clinic role.
      - Profile settings link.
      - Sign Out action (submits to Supabase signout and redirects to `/login`).

### 4. Backdrop & Layout Integration (`app/(dashboard)/layout.tsx`)
- Implement `Backdrop.tsx` (`fixed inset-0 bg-gray-900/40 backdrop-blur-xs z-40 lg:hidden`).
- Update `app/(dashboard)/layout.tsx`:
  - Wrap authenticated layout with `SidebarProvider`.
  - Render `AppSidebar` and `Backdrop`.
  - Main content container adjusts margin dynamically based on sidebar state (`lg:ml-[290px]` expanded vs `lg:ml-[90px]` collapsed).
  - Clean page wrapper with standard max-width container and responsive padding (`p-4 sm:p-6 lg:p-8`).

## Verification
- Desktop sidebar toggles smoothly between expanded (290px) and collapsed (90px).
- Mobile screen (<768px): sidebar is hidden; tapping hamburger slides in drawer; tapping backdrop or nav link closes drawer.
- Role-based navigation items hide for non-admin roles and show for owners/admins.
- Header profile dropdown renders user email, role, and functional sign out.
