# Plan 02.1-01: Foundation, Tokens & Core UI Primitives

**Phase:** 02.1 (Phase 2B) — UI/UX Re-foundation Using TailAdmin Free  
**Plan:** 01 of 05  
**Type:** Design System Foundation  

## Goal
Establish the unified TailAdmin-inspired visual foundation in Tailwind CSS v4, configure necessary utility dependencies, resolve build exclusions, and build a cohesive suite of reusable UI primitives in `components/ui/`.

## Dependencies & Setup
- Add `clsx` and `tailwind-merge`.
- Add `"docs"` to `"exclude"` in `tsconfig.json`.
- Create `lib/utils.ts` exporting the `cn(...)` utility function.

## Detailed Tasks

### 1. Tailwind v4 Theme & Token Configuration (`app/globals.css`)
- Define TailAdmin `@theme` tokens mapped strictly to `DESIGN.md`:
  - **Colors:**
    - `brand`: 50 through 950 scale anchored around canonical `#1769E0` (`brand-500`).
    - `gray`: 25 through 950 neutral scale for surfaces, borders, and text.
    - `success`: emerald scale (50–950).
    - `warning`: amber scale (50–950).
    - `error`: rose/crimson scale (50–950).
    - `info`: light blue scale (50–950).
  - **Surfaces & Borders:**
    - Canvas: `bg-gray-50` (`#F7F6F3` / `#F9FAFB`).
    - Surface Card: `bg-white`.
    - Border Default: `border-gray-200` (`#E4E5E7` / `#E5E7EB`).
    - Border Focus: `focus:ring-brand-500/15 focus:border-brand-500`.
  - **Typography:**
    - `font-sans`: Inter, ui-sans-serif, system-ui.
    - Type scale tokens (`text-title-xl`, `text-title-lg`, `text-title-md`, `text-title-sm`, `text-theme-sm`, `text-theme-xs`).
  - **Shadows:**
    - `shadow-theme-xs`, `shadow-theme-sm`, `shadow-theme-md`, `shadow-theme-lg`.
  - **Utilities:**
    - Custom scrollbar, no-scrollbar, menu-item utilities from TailAdmin.

### 2. Core UI Primitives (`components/ui/`)
- **`button.tsx`**:
  - Variants: `primary`, `secondary` (clean white with border), `outline`, `danger`, `ghost`.
  - Sizes: `sm` (36px), `md` (44px min touch target), `lg` (48px).
  - Features: `startIcon`, `endIcon`, `loading` spinner, `disabled` opacity.
- **`input.tsx` & `field.tsx`**:
  - Styled with TailAdmin form styling (`h-11`, clean border, focus ring, placeholder color).
  - Field wrapper with accessible label, required asterisk, hint text, error message linked via `aria-describedby`.
- **`select.tsx`**:
  - Styled native select control with custom dropdown chevron, matching `input.tsx` height and padding.
- **`card.tsx` / `ComponentCard.tsx`**:
  - Rounded `rounded-xl border border-gray-200 bg-white shadow-theme-xs`.
  - Subcomponents: `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`.
- **`table.tsx`**:
  - Accessible semantic table primitives: `Table`, `TableHeader`, `TableBody`, `TableRow`, `TableCell`, `TableHead`.
  - Styled with subtle borders, muted header background, and row hover states.
- **`badge.tsx`**:
  - Pill badge supporting `variant` (`light` | `solid`) and `color` (`primary`, `success`, `warning`, `error`, `info`, `gray`).
  - Specific presets for clinical states (`Waiting`, `In Consultation`, `Completed`, `Cancelled`, `ABHA`).
- **`modal.tsx` / `dialog.tsx`**:
  - Accessible modal dialog with backdrop overlay, ESC key listener, focus trap, and clean header/body/footer.
- **`dropdown.tsx`**:
  - Contextual dropdown with trigger slot, menu container, and click-outside dismissal (`useClickOutside`).
- **`alert.tsx`**:
  - Inline message card with icon and status colorings (`success`, `warning`, `error`, `info`).
- **`empty-state.tsx`**:
  - Reusable empty state with centered icon container, title, description, and action button.
