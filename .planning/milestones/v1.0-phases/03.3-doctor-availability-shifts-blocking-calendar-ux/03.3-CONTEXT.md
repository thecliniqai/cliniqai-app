# Phase 03.3: Doctor Availability, Multi-Shift Scheduling, Time Blocking & Calendar Enhancements - Context

**Gathered:** 2026-10-16  
**Status:** Ready for planning  

<domain>
## Phase Boundary

Eliminate raw UUID fragments with complete doctor/staff name resolution across all screens; enable doctors and clinic admins to configure weekly split shifts (Morning & Evening) and default appointment slot durations (15, 20, 30, 45, 60m); provide 1-click time-off and date-range blocking (leaves/surgeries/vacations); render dynamic calendar timeline bounds based on active shifts; add interactive doctor filter pills in the calendar header; and support soft-block emergency overrides.

</domain>

<decisions>
## Implementation Decisions

### 1. Doctor & Staff Name Resolution
- **D-01:** Centralized name resolution helper in `features/staff/actions.ts` (`getTenantDoctorDirectory()` and `getTenantStaffDirectory()`). Resolves `memberships.full_name` with fallback to user metadata or clean labels. Completely eliminates raw sliced UUID strings (`Dr. (780d382b)`) from Calendar, Queue, Cabin, Booking Drawer, and Walk-In Drawer. — **Reversibility:** costly — touches multiple UI call sites and server components.
- **D-02:** Standard doctor display format: `Dr. ${fullName}` (if not already prefixed), with clinical specialty badge (e.g., `General Physician`, `Dental`, `Pediatrics`).

### 2. Weekly Shift Scheduling & Day-Off Controls
- **D-03:** Split shifts per day: Two structured shift slots per day ("Morning Shift" and "Evening Shift") with 15-minute time pickers and an enable/disable toggle for Shift 2. Stored on `memberships.availability_schedule` (JSONB). — **Reversibility:** one-way — database migration adding JSONB column to `memberships`.
- **D-04:** Quick-fill presets: "Apply Monday to Weekdays (Mon-Fri)" and "Apply to Mon-Sat" 1-click action buttons to rapidly copy hours across the week.
- **D-05:** Day-off toggles per day (e.g. Sunday disabled by default).
- **D-06:** Clinic operating hours in `/settings` act as informational / letterhead times; the calendar dynamically accommodates whatever active doctor shifts exist on any given day.

### 3. Time-Off & Leave Blocking UX
- **D-07:** `schedule_blocks` table with multi-tenant RLS for doctor-specific and clinic-wide blocks. Fields: `tenant_id`, `doctor_id` (null if clinic-wide), `start_time`, `end_time`, `all_day`, `reason`, `created_by`. — **Reversibility:** one-way — database migration creating `schedule_blocks` table.
- **D-08:** Three distinct modes in `BlockTimeModal`:
  1. "Time Window" (specific hours on a date, e.g. 2:00 PM – 4:00 PM)
  2. "Full Day" (single date)
  3. "Date Range" (multi-day vacation/conference)
- **D-09:** Quick preset chips for block reasons: `Leave / Vacation`, `Surgery / Procedure`, `Personal Break`, `Conference`, `Emergency` plus custom reason notes.
- **D-10:** Existing appointment conflict handling: If appointments are already booked in the window being blocked, display a warning banner listing conflicts, but permit creating the block with an amber conflict badge for front-desk rescheduling.

### 4. Dynamic Calendar Hours & Doctor Filter Pills
- **D-11:** Filter pill bar in `CalendarView` header: `[ All Doctors (N) ]` and individual doctor pills `[ Dr. {Name} ({Specialty}) ]`.
  - Single-click on a doctor pill isolates to that doctor's column.
  - Clicking `All Doctors` restores all doctor columns.
  - Clicking additional doctor pills toggles multi-doctor comparison.
- **D-12:** Smart dynamic timeline bounds: Auto-computes the earliest start time and latest end time across all visible doctors for the selected date (e.g. 10:00 AM to 9:00 PM), with minimum 08:00 AM and maximum 21:30 PM bounds, preventing unnecessary vertical scrolling.
- **D-13:** Timeline grid styling:
  - Off-duty intervals (e.g. between morning and evening shifts) render with a muted light gray background and subtle "Off Duty" text.
  - Blocked intervals render with amber-tinted diagonal hatching, block reason tag, and lock indicator.

### 5. Multi-Slot Appointment Display & Emergency Override Dialog
- **D-14:** Default slot duration per doctor: Stored in `memberships.default_slot_duration_minutes` (INTEGER default 15). Pre-populates the duration dropdown in `BookingDrawer` (e.g., 45m for Dentist, 15m for GP). Preset durations: 15m, 20m, 30m, 45m, 60m, 90m. — **Reversibility:** one-way — database migration adding column.
- **D-15:** Multi-slot visual occupancy: A visit lasting >15 mins (e.g. 45m) renders as a single continuous card spanning the full multi-slot height (e.g. 3 consecutive 15-minute grid slots), displaying start time, end time, and duration badge, while blocking underlying slots from double-booking.
- **D-16:** Soft-block emergency override: Clicking an off-duty or blocked slot opens `SoftBlockOverrideDialog` displaying the doctor's shift/block reason and requiring an emergency reason before launching the booking drawer with `is_overbooked: true` / emergency override flag.

### the agent's Discretion
- Exact Tailwind CSS classes for the diagonal hatching on blocked slots (`bg-[repeating-linear-gradient(...)]` conforming to `DESIGN.md`).
- Exact layout of time picker selects (15-min intervals from 06:00 to 23:45).
- Placement of the "+ Block Time" button in both Calendar view header and Doctor Profile card.

</decisions>
